# Blue Cipher Works signature assets

Repository pubblico dedicato esclusivamente agli asset HTTPS delle firme email
di Blue Cipher Works (BCW). I file sono pubblicati con percorsi opachi derivati
da SHA-256 e non devono contenere credenziali, token, messaggi o dati privati.

`robots.txt` richiede ai crawler conformi di non indicizzare alcun percorso.
Gli asset restano pubblicamente recuperabili da chi conosce l'URL, requisito
necessario per il rendering delle immagini remote nelle firme Gmail.
